🛡️ Group 01 · Foundation & Safety 5 Features

None of these are features anyone asks for. All of them are the reason the rest can exist.

Feature #1 Blocker

Log in with an account

The app has no login at all. Add sign-in, so the app knows who you are and only shows your data.

📌 Technical Note
Today: no auth layer anywhere in the codebase.
Feature #2 Blocker

Lock the database

The security rules on every table are currently set to "allow everyone." Anyone who finds the web address can read and change everything in it.

📌 Technical Note
Every RLS policy reads USING (true) with the public key shipped to the browser.
Feature #3 Blocker

Replace the leaked keys

Three secret keys are written directly into a file that ships with the code, including one that lets anyone send notifications to your phone. Generate new ones and store them properly.

📌 Technical Note
Supabase URL, anon key and the VAPID private key are all in wrangler.jsonc.
Feature #4 Blocker

Keep working without internet

Save entries on the phone when there's no signal and send them up automatically when there is.

📌 Technical Note
The service worker handles push only — no caching, no background sync.
Feature #5 Blocker

Back up and download everything

Automatic backups, plus a button that gives you your entire history as a file you can keep.

✂️ Group 09 · What to Drop 3 Features

Features that sound good on paper but add unnecessary complexity.

Part Two · Features 30–64

Making the App Easier to Use

Same app, same data. These 35 interface and UX refinements change how it feels to open the app twenty times a day.

🎨 Group 10 · Text, Weight & Colour 5 Features

Consistent text hierarchy, single colour system, and clean visual weight.

Feature #30 Then

Pick five text sizes and stick to them

Right now sizes are chosen at random throughout the app, and a lot of them are 9 or 10 pixels — smaller than the small print on a contract. Settle on roughly five sizes and retire everything below 12.

Feature #31 Then

Stop making everything bold

Use three weights — normal for text, semibold for emphasis, heavy for the one thing that matters most on a screen. Currently the heaviest weight is the default.

Feature #32 Then

Drop the tiny ALL-CAPS labels

Wide-spaced capitals at 9 pixels appear 433 times. Capitals remove the shape of a word, which is what your eye reads first, so they’re the slowest text there is.

Feature #33 Then

Use one colour system

The app defines proper colours for success, warning and danger, then ignores them — 134 places use hardcoded colours instead.

Feature #34 Then

Make all charts look the same

One shared set of colours, fonts and spacing for every graph.

🧭 Group 11 · Getting Around the App 6 Features

Bottom tab navigation, header improvements, and fast section jumping.

Feature #35 Then

A row of tabs along the bottom

Four main destinations plus a big centre button for logging, fixed at the bottom of the screen where your thumb already is. Keep the side menu for everything else.

Feature #36 Then

Remove the Forward button

Every page shows Home, Back and Forward. A forward button is a web-browser control, not an app one, and the three of them eat about a third of the header on a phone.

Feature #37 Then

Put the header to better use

The app logo sits in the middle of every screen. In an app you installed yourself, you already know which app it is. Use that space for the page title and search.

Feature #38 Then

Type-to-jump shortcut

One box that finds any screen, entry or record by name.

Feature #39 Then

One tab style, and fix the Reports tabs

There are two different tab components doing the same job, styled differently. Also, Reports has eleven tabs that scroll sideways — anything off-screen may as well not exist.

Feature #40 Then

A proper layout on a computer

On a wide screen the app stretches the frame but keeps content in a narrow phone-width column, leaving large empty margins. Either build a real multi-column layout or stop pretending.

📝 Group 12 · The Forms You Use Daily 5 Features
